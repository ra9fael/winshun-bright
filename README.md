# ra9fael.bright — Win顺 屏幕亮度插件

Ctrl+Alt+滚轮全局调亮度（内屏 WMI、外屏 DDC/CI），Ctrl+Alt+点击开关暖色滤镜；`bright` 关键字按显示器逐台调节。浮层与手势架构复用 ra9fael.volume。
